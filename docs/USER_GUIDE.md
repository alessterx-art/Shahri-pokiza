# Дастури Корбар (User Guide) — Шаҳри Покиза

"Шаҳри Покиза" як низоми ягонаи электронии назорати тозагӣ ва партовҳо мебошад.

## Нақшҳои асосӣ (Roles)

### 1. Шаҳрванд (Public User)
- **Хабар додани ифлосшавӣ**: Гирифтани акс бо телефон ё боргузорӣ, интихоби нуқта дар харитаи шаҳр, таҳлили фаврии сунъӣ (AI) ва ирсоли арз.
- **Харитаи тозагӣ**: Дидани қуттиҳои фаъоли шаҳр ва ҳолати онҳо.
- **Эко-холҳо**: Гирифтани холҳои ҳавасмандӣ барои гузоришҳои тасдиқшуда ва дидани ҷадвали пешсафон.

### 2. Корманди тозагӣ (Sanitation Worker)
- **Супоришҳои фаврӣ**: Дидани корҳои вобасташуда бо акс, суроға ва дараҷаи муҳиммият.
- **Раванди тозакунӣ**: Қабули кор ("Дар иҷро"), гирифтани акси "Пеш аз тозакунӣ" ва "Баъд аз тозакунӣ", сабти анҷоми супориш.
- **Таърихи корҳо**: Назорати иҷрои нақшаи рӯзона.

### 3. Мудири бахши коммуналӣ (Administrator)
- **Панели идоракунӣ**: Омори пурраи қуттиҳо, ҳодисаҳо, кормандони фаъол ва харитаи гармии ифлосшавӣ.
- **Вобастакунии супориш**: Таъин кардани ҳодисаҳои нав ба коргарони мушаххас.
- **Камераҳои назоратӣ (CCTV)**: Тафтиши ҳодисаҳои видеоӣ, таҳлили аксҳо ва сабти расмии қонуншиканӣ.
- **Журнали аудит**: Сабти ҳамаи амалиётҳо ва тағйироти вазъ.
